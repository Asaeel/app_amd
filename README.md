

# app_amd

## Introduction

This project is a mobile application created using Flutter.
The app aims to help users manage different aspects of their daily life, such as goals, relationships, finances, and family connections.
It contains several pages that make it easy to track personal progress and organize information in a simple way.
The main focus of this version is on the design, navigation, and structure of the app rather than advanced backend or AI features.

---

## Objective

The main goal of this project is to design a complete Flutter app that includes multiple sections related to personal development, motivation, and family interaction.
It provides a simple interface where the user can record goals, track achievements, and explore helpful content such as family, money, and spiritual reminders.

---

## Project Overview

The project consists of several pages, each with a specific purpose:

| File                                                | Description                                             |
| --------------------------------------------------- | ------------------------------------------------------- |
| `SignupPage.dart`                                   | Page for user registration.                             |
| `Nextpage.dart`                                     | Navigation page that connects the main sections.        |
| `home.dart`                                         | The main page of the application.                       |
| `goals.dart`                                        | Page for writing and managing personal goals.           |
| `familylove.dart` and `fmlovemore.dart`             | Pages related to family relationships and love.         |
| `addfamily.dart`                                    | Page for adding or viewing family members.              |
| `adkar.dart`                                        | Page that displays religious reminders or daily Adhkar. |
| `money.dart`                                        | Section related to money or financial tracking.         |
| `bag.dart`, `gift.dart`, `share.dart`, `print.dart` | Pages for tools such as gifts, sharing, and printing.   |
| `analys.dart` and `addanalys.dart`                  | Prepared for analysis or statistics features.           |
| `detels.dart`                                       | Details page for specific items.                        |
| `finally.dart`                                      | Ending or summary page.                                 |
| `main.dart`                                         | The main entry point of the app.                        |

---

## Features

* Organized multi-page design.
* Registration and navigation system.
* Goal tracking and family management pages.
* Financial section for recording or viewing data.
* Adhkar (religious reminders) page for spiritual content.
* Sharing, printing, and extra tools integrated into the app.
